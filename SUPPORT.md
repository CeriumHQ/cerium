# Getting help

- **Something isn't working:** check **Settings → Harnesses** first. It shows each harness's
  version, whether Cerium has tested it, and how it's signed in, and **Check again** re-probes them.
- **Questions, ideas and show-and-tell:** start a
  [discussion](https://github.com/CeriumHQ/cerium/discussions).
- **Bugs:** search the [issues](https://github.com/CeriumHQ/cerium/issues), then open one with the
  bug template if it's new.
- **Security problems:** see [SECURITY.md](SECURITY.md).

A harness's own login, billing or model behaviour is up to its vendor: Anthropic for Claude Code,
OpenAI for Codex, Meta for Muse Code, Cursor for Cursor and Anomaly for OpenCode.
