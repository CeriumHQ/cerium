One thread. Every agent.

A local-first desktop app for Claude Code, Codex, Cursor, and six more coding agents, running on the subscriptions you already pay for.

Download for Windows See a thread

Free and open source (Apache 2.0) for Windows, macOS, and Linux.

Delegate across harnesses

Prompt a lead agent once. It assigns subtasks to any signed-in harness with scoped permissions, while every subagent transcript stays open live.

Nine harnesses, direct sign-in

Install any of these locally and sign in as usual. Cerium detects them automatically, never reads your tokens or API keys, and adds no proxy or markup.

Automations and CI recovery

Trigger threads on a schedule, on GitHub events, or when CI fails. Cerium pulls the failed logs, fixes the break in a fresh git worktree, and pushes again.

Worktrees and checkpoints
Isolated git worktrees per thread with inline staging, commits, and PRs. Turn checkpoints restore conversation and files together.
Mid-task failover
Hit a rate limit and switch harnesses mid-thread. Your conversation history, file changes, and plan come along.
Terminals, preview, and computer use
Per-thread shells, an inspectable browser preview agents can drive, and opt-in computer use with live per-agent cursors.
Phone and web access
Optional sign-in syncs desktop threads to the web app, with push notifications when an agent finishes or needs approval.
Shared Hub and import
Manage MCP servers, skills, and project instructions across harnesses, and import existing sessions from eight CLIs.
Forks, /btw, and dictation
Fork threads at any turn, ask /btw side questions, work in split panes, and dictate offline with local Whisper.

Fourteen themes, dark and light

Each palette styles the chrome, accent, and syntax colors together. Pick one to preview it on this page.

Local-first architecture

Cerium runs no agent loop of its own and proxies nothing. It coordinates your local harnesses over an injected MCP bus and writes every event to SQLite.

No telemetry
Zero usage analytics. Scrubbed crash reports can be turned off in Settings.
Local SQLite log
Every thread and subagent transcript stays on disk.
Optional sign-in
Used only to sync threads to the web app and phone. Privacy policy
