Privacy

Cerium collects no telemetry or usage analytics. Threads stay in a local SQLite database on your machine, and each harness connects directly to its own provider. Anonymous crash reporting is on by default and can be turned off in Settings.

Everything Cerium stores or sends off your machine is listed below.

Optional account & sync

Signing in is optional and only needed to view or steer desktop threads from your phone or another device. Clerk handles authentication (email and password, Google, GitHub, or X) and receives your name, email address, and profile picture. Cerium never sees your password.

When signed in, the relay at cerium.nonlooped.xyz stores:

  • Your name, email address, and profile picture from your sign-in provider
  • Device metadata: name, platform, Cerium version, update channel, last-seen time, and a hash of the device key
  • Synced threads from signed-in machines: messages, tool calls, and tool outputs (images excluded)
  • Unsent drafts and per-thread read positions
  • Browser push subscriptions, if you enable notifications

During remote control, the relay proxies live traffic between your devices. It runs on Cloudflare, which keeps standard request logs. Your data is never sold or shared for advertising.

Deleting your data

Signing out a machine (or removing it in Settings → Account) deletes its synced threads from the relay. Deleting a thread removes its synced copy immediately. To delete your entire account, open an issue on GitHub from your signed-in account, or ask there for a private contact.

Network requests

Crash reports
On unexpected failures (UI render errors, backend crashes, unexpected harness exits, or failed updates), the desktop app sends an anonymized report to Sentry. Reports include the error type, a scrubbed message (file paths, URLs, email addresses, IPs, and IDs removed), Cerium's stack trace, app version, update channel, OS, and CPU architecture. Reports never include messages, files, folder or project names, thread titles, account details, machine names, or memory contents, and Sentry does not store your IP address. Disable anytime in Settings → General → Send crash reports.
Updates
Cerium checks GitHub Releases on launch and every six hours, downloading updates only when you choose to install them. Opening Settings → Harnesses checks npm and GitHub for newer CLI versions.
Dictation
On first use, Cerium downloads the local speech runtime (GitHub Releases, with Unpkg as fallback) and your chosen Whisper model (Hugging Face). Both are cached locally; transcription runs entirely on your machine.
Artifacts
Interactive HTML artifacts generated by agents can load external HTTPS scripts (for example, charting libraries from cdn.jsdelivr.net), which your client fetches when you view them.

This website

This website runs no analytics, trackers, or ads. Signing in sets Clerk session cookies to keep you authenticated. Cloudflare serves the site and retains standard request logs. Your selected theme is saved only in your browser.
